# Задача 8
Напишите программу для вычисления стоимости поездки на такси. Ваша программа должна учитывать следующие параметры:

- Расстояние (в километрах).
- Время (в минутах).
- Тип такси (например, эконом, стандарт, бизнес).

Для расчёта стоимости поездки:

- Базовая стоимость составляет 50 рублей за посадку.
- Стоимость километра зависит от типа такси:
- - Эконом: 10 рублей/км
- - Стандарт: 15 рублей/км
- - Бизнес: 25 рублей/км
- Стоимость времени: 5 рублей за каждую минуту.
- Функция должна принимать три параметра: `тип такси`, `расстояние` и `время`.
- Функция должна вернуть два значения: `итоговую стоимость` и `описание типа такси`.
- Напишите функцию `calculateFare`, которая будет рассчитывать стоимость и описание поездки в зависимости от параметров. Функция должна также обрабатывать неверные типы такси.
